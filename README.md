# Mobile-Sales-Dashboard
Power BI dashboard project using Excel, Power Query, and DAX

## Project Overview
This project is an interactive Power BI dashboard developed to analyze Motorola mobile sales performance. The dashboard transforms raw sales data into meaningful business insights that help monitor sales, quantity, revenue trends, customer behavior, and regional performance.

The project demonstrates practical Data Analyst skills including data cleaning, transformation, data modeling, DAX calculations, and dashboard visualization.

## Project Objectives
Analyze overall sales performance of Motorola products.
Identify top-performing months and products.
Track quantity sold, revenue, and profit trends.
Compare sales across regions and categories.
Build an interactive dashboard for business decision-making.
Generate data-driven insights for improving sales performance.

## Business Problem

Motorola sales data was available in raw Excel format, making it difficult to:

Monitor sales performance in real time.
Identify high-performing products and regions.
Track monthly sales trends and KPIs.
Make quick business decisions using raw tabular data.

This dashboard solves the problem by providing a visual and interactive reporting solution that allows users to explore sales data efficiently.
